# キャバ帳 リリース手順（Firebase Hosting・無料構成）

外部URLで**完全に動く**状態にするための手順。構成は次のとおり。

| 領域 | 使うもの | 料金 |
|---|---|---|
| フロント配信 | Firebase Hosting（静的PWA） | 無料(Spark) |
| 認証 | Firebase Auth（Google ログイン） | 無料 |
| データ | Cloud Firestore | 無料枠 |
| AI（返信案・特別連絡・黒服相談・相性診断） | **Groq 無料API をクライアントから直接呼び出し** | 無料 |

> Cloud Functions（有料Blaze）は使いません。AIキーを秘匿したくなったら、後から
> `VITE_AI_PROXY_URL` にサーバ経由プロキシを差すだけで、コード変更なしに切替できます。

---

## A. あなた（オーナー）がコンソールで行う作業

> Google/Firebase アカウントの操作は代行できないため、ここはご自身で。

### 1. Firebase プロジェクト作成
1. https://console.firebase.google.com/ →「プロジェクトを追加」
2. プロジェクトID は **`points-optimizer-app`** を推奨（別IDにする場合は後述の値も合わせて教えてください）
3. Google アナリティクスは任意（無しでOK）

### 2. ウェブアプリを登録して構成値を取得
1. プロジェクト概要の **`</>`（ウェブ）** アイコンでアプリ登録（ニックネーム自由、Hosting のチェックは任意）
2. 表示される `firebaseConfig` の以下6値を控える（後で私に渡す）
   - `apiKey` / `authDomain` / `projectId` / `storageBucket` / `messagingSenderId` / `appId`

### 3. Google ログインを有効化
1. 左メニュー **Authentication →「始める」**
2. **Sign-in method → Google → 有効化** → サポートメール選択 → 保存

### 4. Firestore データベース作成
1. 左メニュー **Firestore Database →「データベースの作成」**
2. **本番環境モード**を選択（ルールは私がデプロイします）
3. ロケーションは **`asia-northeast1`（東京）**

### 5. Groq 無料APIキー取得
1. https://console.groq.com/keys にGoogleでログインしAPIキーを発行
2. キー文字列を控える（`gsk_...`）

### 6. デプロイ用トークン発行（あなたのPCで一度だけ）
```bash
npm i -g firebase-tools
firebase login:ci
```
ブラウザ認証後に表示される **`1//...` のトークン**を控える。

---

## B. 私（Claude）に渡すもの

上記が終わったら、次をまとめて送ってください。**チャットに直接貼らず**、機微情報の受け渡し方法はご相談可（ただし迅速にデプロイするには必要）。

```
FIREBASE_API_KEY=...
FIREBASE_AUTH_DOMAIN=points-optimizer-app.firebaseapp.com
FIREBASE_PROJECT_ID=points-optimizer-app
FIREBASE_STORAGE_BUCKET=points-optimizer-app.appspot.com
FIREBASE_MESSAGING_SENDER_ID=...
FIREBASE_APP_ID=...
GROQ_API_KEY=gsk_...
FIREBASE_TOKEN=1//...
```

## C. 私が実行する作業（自動）
1. 受け取った値で `.env.production` を生成（リポジトリにはコミットしない）
2. `npm run build`（型チェック＋本番ビルド）
3. `npx firebase-tools deploy --only hosting,firestore --project <id> --token <token>`
   （Hosting・Firestoreルール・インデックスを配備。Functions は対象外）
4. 発行された公開URL（`https://<project>.web.app`）をお伝えします

## D. デプロイ後、あなたが1つだけ行う作業
- Firebase コンソール **Authentication → Settings → 承認済みドメイン** に、
  払い出された **`<project>.web.app`** と **`<project>.firebaseapp.com`** が入っているか確認
  （通常は自動で入りますが、Googleログインが弾かれる場合はここを確認）

## セキュリティ注記
- `VITE_GROQ_API_KEY` は静的バンドルに埋め込まれ、閲覧者から見えます。Groq無料枠のため
  実害は「レート制限の悪用」に限定されますが、気になる場合は
  Groq コンソールでキーのローテーション運用、または将来 `VITE_AI_PROXY_URL`
  （サーバ側でキー秘匿）へ移行してください。
- 顧客の個人情報は Firestore セキュリティルール（`firestore.rules`）で
  本人(uid)のみアクセス可能に制限済み。店舗コンソールは個人領域を参照できません。
