# クロードデザイン 貼り付け用プロンプト（そのままコピペ可）

実際の型（`src/types`）とサンプルデータ（`src/fixtures/sample.ts`）を埋め込んだ**完成版プロンプト**。
クロードデザイン（claude.ai の Artifact）に貼るだけで、このリポジトリへ near-1:1 で移植できるReactモックが出る。

---

## 渡し方（手順）

1. **claude.ai を開く** → キャバ帳の Project（「キャバ帳アプリUIプロンプト集」がある場所）で**新規チャット**を作成。
   - Project に入れておくと、UIプロンプト集の規約が自動で効く。無ければ普通のチャットでもOK。
2. 下の **「① 顧客詳細 プロンプト」を丸ごとコピペ**して送信。
3. **Artifact（React コンポーネント）が生成**される。プレビューで確認し、直したい所は続けて「ヘッダーをもっと余白」等と口頭で修正。
4. 気に入ったら **Artifact右上からコードを全選択コピー**（または Artifact のURLを控える）。
5. **クロードコード（このリポジトリのセッション）に戻り**、そのコードを貼って
   「これを `src/pages/cast/CustomerDetail.tsx` に移植して」と依頼。
   - こちらで **ダミー`const data` → `sampleCustomer`(fixture) → Firestore取得** の順に差し替えて結線する。
6. 他の画面は末尾の「差し込み早見表」で型/データを差し替えて同じ手順。

> ポイント：本アプリは **React + Tailwind + 同じトークン（night/gold）** なので、モックのクラスはそのまま通り、移植は最小の手直しで済む。

# データ契約（TypeScript）── props はこの型に厳密に一致させること
（Timestamp は Firestore の Timestamp。UIでは `toDate(): Date` で表示。モック内では { toDate: () => Date } とみなしてよい）
```ts
type Yen = number
type CustomerRank = 'VVIP' | 'VIP' | 'IP' | 'LOVE' | 'BADBOY'   // 1番の太客/定期太客/見込み/スキピ/痛客
type FitLevel = '得意' | '普通' | '苦手'
type Fatigue = '低' | '中' | '高'
type PaymentMethod = 'cash' | 'card' | 'urikake'

interface Fit { level: FitLevel; reasonTags: string[]; fatigue: Fatigue; note?: string }
interface Bottle { name: string; price: Yen }

interface Customer {
  id: string
  nickname: string           // あだ名（必須）
  lineName?: string
  occupation?: string
  companyName?: string
  incomeRange?: string
  paymentMethods: PaymentMethod[]
  tags: string[]
  rank?: CustomerRank
  fit?: Fit
  pinnedCautions: string[]   // F-14 ピン留めした注意点
  totalSpent: Yen            // 累計（自動集計）
  visitCount: number
  riskScore: number          // F-02（0-100）: >=50 黄 / >=70 赤
  riskFlags: string[]
  memo?: string
}

interface Visit {
  id: string
  date: { toDate: () => Date }
  durationMin?: number
  amount: Yen
  bottles: Bottle[]
  isDohan: boolean
  isAfter: boolean
  payment: PaymentMethod
  urikakePaid?: boolean
  episodeMemo?: string
}

interface Props { customer: Customer; visits: Visit[] }
```

# コンポーネント仕様
- 単一の表示専用 React コンポーネント `CustomerDetail({ customer, visits }: Props)` を export
- 内部でデータ取得はしない（props で受け取る）
- 上部: プロフィールカード（あだ名・ランクバッジ・職業・累計/来店/リスクの3指標）
- リスク: riskScore>=50 で黄アラート、>=70 で赤アラート帯＋riskFlagsを表示（F-02）
- ランク: VVIP/VIP/IP/LOVE/BADBOY をバッジ表示（色分け）
- 相性(fit): 得意=緑/苦手=赤/普通=グレーのチップ＋理由タグ（F-13）
- 気をつけること: pinnedCautions をリスト表示（F-14）
- 来店履歴: visits を新しい順の縦タイムライン。日付/金額/同伴/アフター/滞在/支払/ボトル/エピソード（F-03）

# 出力制約（クロードコードへの移植のため厳守）
- React + Tailwind CSS のみ。外部ライブラリは React 以外使わない（アイコンはインラインSVGか絵文字）
- 色は Tailwind の `night`(=#1f1147) / `gold`(=#c9a24b) を使う。その他は標準Tailwind
- 画面上部ヘッダーは `padding-top: max(env(safe-area-inset-top), 12px)`（セーフエリア対応）
- ダミーは全て1箇所の `const data` に置き、削除しやすくする
- 1ファイルで返す

## 差し込み早見表（他の画面に流用）

上の「データ契約」「サンプルデータ」「画面仕様」だけ差し替えれば他画面も同様に作れる。型は `src/types`、データは `src/fixtures/sample.ts` からコピー。

| モック画面 | 差し込む型 | 差し込むfixture | 移植先 |
|---|---|---|---|
| ① ホーム/ダッシュボード | `Schedule`/`SalesRecord`/`Customer` | `sampleSchedules`/`sampleSalesRecord`/`sampleCustomer` | `pages/cast/CastHome.tsx` |
| ② 顧客詳細（上記） | `Customer`/`Visit` | `sampleCustomer`/`sampleVisits` | `pages/cast/CustomerDetail.tsx` |
| ③ LINE返信案 | `ReplySuggestion`/`LineImport` | `sampleReplySuggestions` | `pages/cast/ReplyAssist.tsx` |
| ④ 黒服相談 | `Consultation`（`{role,text}[]`） | （会話サンプルを数往復でっち上げ） | `pages/cast/Consult.tsx` |
| ⑤ 売上レポート | `SalesRecord`/`Ranking` | `sampleSalesRecord`/`sampleRanking` | `pages/cast/SalesReport.tsx` |
