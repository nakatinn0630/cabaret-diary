# クロードコード ⇄ クロードデザイン 橋渡しガイド

2つの環境を行き来しながら「デザイン → 実装」を回すための手順。

- **クロードデザイン**（claude.ai / Artifact）：見た目・UIモックを作る。ダミーデータで動く単体HTML/React。
- **クロードコード**（このリポジトリ）：実データ・Firebase・型に結線し、本物のアプリにする。

## 橋渡しの"共通通貨" = 契約 ＋ サンプルデータ ＋ トークン

2環境がズレないための共有物は次の3つ。これを毎回受け渡す。

| 共通通貨 | 実体 | 役割 |
|---|---|---|
| **契約（型）** | `src/types/*.ts` | props の形を一致させる |
| **サンプルデータ** | `src/fixtures/sample.ts` | 同じ形の実例で描かせる／検証する |
| **トークン** | `tailwind.config.js`（`night`/`gold`） | クラス名を一致させ、見た目を移植可能に |

> ポイント：本アプリは **React + Tailwind + 同じトークン**。だからクロードデザインの出力を **near-1:1** で移植できる。ここが崩れると橋が壊れる。

---

## 往復フロー（1画面あたり）

```
[クロードコード]                         [クロードデザイン]
 1. 型 + fixture を用意 ───(コピペ)──▶ 2. 依頼プロンプトに差し込み
                                          （docs/design/クロードデザイン依頼プロンプト.md）
                                        3. モック生成（props=契約、data=fixture）
 5. リポジトリへ移植 ◀──(コピペ/保存)── 4. 出来たReactコードを受け取る
 6. ダミー→fixture→Firestore に差し替え
 7. typecheck / 稼働確認
```

### 各ステップの具体
1. **契約とデータを出す**（クロードコード）：対象画面が使う型（例 `Customer`/`Visit`）と `sample*` を用意。無ければ先に型を追加。
2. **依頼**（クロードデザイン）：`docs/design/クロードデザイン依頼プロンプト.md` のテンプレに型・データを貼って依頼。
3. **生成**：props が契約に一致し、ダミーは `const data` に隔離された単体モックが出る。
4. **受け取り**：出力Reactコードをコピー（または `.tsx` として保存）。
5. **移植**（クロードコード）：`src/pages/...` か `src/components/...` に配置。Tailwindクラスはトークンが同じなのでそのまま通る。
6. **データ差し替え**（3段階）：
   - `const data`（モック内ダミー）→ `import { sampleCustomer } from '@/fixtures/sample'`（型検証済みの共有fixture）
   - → `useCustomer(cid)` など Firestore 取得フックへ（本実装）
   - コンポーネントは**表示専用**のままにし、データ取得は親/フックに置く（差し替えが1箇所で済む）
7. **検証**：`npm run typecheck` と稼働確認（ロードマップの「稼働確認前にデザイン修正」ゲートを通す）。

## 受け渡しの実務メモ

- **方向A（コード→デザイン）**：`src/types` と `src/fixtures/sample.ts` の該当箇所をコピペ。これが「動的にコード・データを渡す」の実体。
- **方向B（デザイン→コード）**：
  - 手軽：出力コードをこのチャットに貼る → クロードコードが移植・結線。
  - 記録重視：モックHTML/コードを `docs/design/briefs/<screen>.tsx` として保存し版管理。
- **トークンは1本化**：色を足したくなったら `tailwind.config.js` に追加し、その名前を依頼プロンプトにも書く（両環境で同じ名前）。
- **presentationalを守る**：モックも実装もデータは props。これで「ダミー→fixture→Firestore」がすべて親側の一行差し替えになる。
- **セーフエリア**：ヘッダーは `max(env(safe-area-inset-top), 12px)`（実装側は `.safe-top` ユーティリティ済み）。
