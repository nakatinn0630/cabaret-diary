# クロードデザイン 依頼プロンプト（コード・データ差し込み型）

クロードデザイン（Claude の Artifact）に「実装に移せるUIモック」を依頼するための**テンプレート**。
`{{...}}` の枠に、**型（契約）・サンプルデータ・既存コード**を差し込んで使う。差し込む素材はこのリポジトリの `src/types/` と `src/fixtures/sample.ts` からそのままコピーできる。

- 目的：出力されたモックを**このリポジトリへ near-1:1 で移植**できる形にすること。
- 前提：本アプリは React + Tailwind、トークンは `night(#1f1147)` / `gold(#c9a24b)`。同じトークンで描かせると移植が楽。

---

## 差し込みの早見表

| 枠 | 入れるもの | 取得元 |
|---|---|---|
| `{{TYPES}}` | 対象画面が使う型定義 | `src/types/*.ts`（該当型をコピー） |
| `{{FIXTURE}}` | サンプルデータ | `src/fixtures/sample.ts`（該当export） |
| `{{SCREEN_NAME}}` | 画面名 | 例: 顧客詳細（リスクアラート付き） |
| `{{FEATURE_IDS}}` | 関連機能 | 例: F-01 / F-02 / F-03 / F-12〜14 |
| `{{COMPONENT_NAME}}` | コンポーネント名 | 例: `CustomerDetail` |

既存コードを渡して「これを改修して」と頼む場合は、末尾に次を足す：

```
# 既存コード（これを土台に改修する）
```tsx
{{EXISTING_CODE}}
```
```

## 記入例：顧客詳細画面（②リスクアラート付き）

`{{TYPES}}` に `Customer`/`Visit`/`Compatibility`（`src/types/customer.ts`）、`{{FIXTURE}}` に `sampleCustomer`/`sampleVisits`/`sampleCompatibility`（`src/fixtures/sample.ts`）を貼り、以下を埋めた例：

```
# 対象画面
- 画面名: 顧客詳細（リスクアラート付き）
- 目的: 顧客プロフィール・累計・ランク・リスク・来店タイムライン・相性の注意点を一望する
- 関連機能ID: F-01 / F-02 / F-03 / F-12 / F-13 / F-14

# コンポーネント仕様
- コンポーネント名: CustomerDetail
- props: { customer: Customer; visits: Visit[]; compatibility?: Compatibility }
- リスクスコア>=50 は黄アラート、>=70 は赤アラート帯を表示（F-02）
- rank はバッジ表示（VVIP/VIP/IP/LOVE/BADBOY）。pinnedCautions を「気をつけること」として表示（F-14）
```

これで返ってくるモックは、props が `Customer`/`Visit`/`Compatibility` に一致しているため、
リポジトリでは `import { sampleCustomer } from '@/fixtures/sample'` を渡すだけで表示でき、
最終的に Firestore 取得へ差し替えるだけで実装が完了する（→ 橋渡しガイド参照）。
